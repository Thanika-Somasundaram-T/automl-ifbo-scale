# Ex2 — Width Interpolation

## Purpose

Test whether iFBO can predict a middle target scale better when context includes the nearest lower and nearest higher target scales.

## Policies

- `bracket_nearest` — primary interpolation policy; requires both lower and higher partner target scales.
- `prefix_only` — no partner curves, target prefix only.
- `all_context_oracle` — all non-query trajectories as an explicitly labeled oracle baseline.

Lower-only and higher-only transfer policies belong to Ex3 width extrapolation, not this interpolation experiment.

## Outputs

- `results/predictions.parquet`
- `results/_partial/{policy}__obs{tag}.parquet`
- `results/uncertainty_diagnostics.csv`
- `plots/_summary/`
- `plots/obs_<NNN>/supervisor_styles/<policy>/`
- `plots/obs_<NNN>/cascade_styles/` when generated by future plotters
